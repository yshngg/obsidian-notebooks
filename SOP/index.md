# Standard operating procedure

> A **standard operating procedure** (**SOP**) is a [standardized](https://en.wikipedia.org/wiki/Standardized "Standardized") way of doing a [task](https://en.wikipedia.org/wiki/Task "Task") or the set of step-by-step instructions that [document](https://en.wikipedia.org/wiki/Documentation "Documentation") how it is done. SOPs are compiled by an [organization](https://en.wikipedia.org/wiki/Organization "Organization") to help workers carry out routine operations.[[1]](https://en.wikipedia.org/wiki/Standard_operating_procedure#cite_note-1) SOPs aim to achieve efficiency, quality output, and uniformity of performance, while reducing [miscommunication](https://en.wikipedia.org/wiki/Miscommunication "Miscommunication") and failure to comply with [industry regulations](https://en.wikipedia.org/wiki/Industry_regulation "Industry regulation").
